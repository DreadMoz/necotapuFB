「ねこたぷ」とは小学生向けタイピングアプリだ。
・Unity Version 2021.3.24f1で作っている。
・シーンはタイトルシーン、ワールドシーン、タイピングシーンの３つ
・タイピングシーンではテキストデータを読み込んでそこに記載されている内容をタイプするよう指示する。この内容をお題という。


これまでの経緯を説明しよう。
２０２４年までにねこたぷの「いいネットなら版」は完成している。
「いいネットなら」とは、奈良県の公立学校向け Google Workspace for Education のことだ。ドメインは「e-net.nara.jp」
Unityで作ったものをGitのスペースにデプロイして、htmlをいいネットならのわたしのアカウントのGASで管理し、ドメイン内でしかアクセスできないように作った。
お金を一切かけないという前提なので、データベースは使わず、私のいいネットならアカウントのスプレッドシートにユーザー情報やランキング情報を持たせて、アプリからアクセスさせていた。アクセスの混雑を避けるため、１日１回程度のアクセス制限を設け、それ以外のときはブラウザに保存をさせていた。

２０２５年に一般版を作ろうというプロジェクトがスターとした。
本プロジェクトはねこ隊長である私とねこ隊員の前世とで作ってきた。
いいネットなら版からの変更点は以下のとおり
・FirebaseのFirestoreをデータベースとして使う。以前のスプレッドシートの内容をFirestoreに移す。
・Firestoreは従量課金制のため、これのアクセスも１日１回程度の制限をかけ、以前のブラウザ保存は残す。
・デプロイ先もFirebaseにしている。（テスト環境も）
・基本的にお金はかけない方針。多少の出費は許容する。
・管理は引き続きGithubで行う。
・Unityのバージョンも（2021.3.24f1）で以前と同じ
・Google、Microsoft、メールアドレスでの登録を可能としている。（Microsoft、メールアドレスの実装は保留中）
・サーバー（リーグ）はドメインによって分ける。
・リーグ内の各ユーザーの情報更新は１日１回バッチ処理にて行う。
・リーグの組み換えは１週間に１回バッチ処理にて行う。（未実装かも）

２０２６年にいよいよ一般版の仕上げにかかる
　◯文字入力の判定のOS依存を回避。UnityからJSに変更（押したキーではなく、入力文字での判定）
　◯子供が学校で使う端末のポップアップブロックを回避
　◯正しい指でキー入力をさせる訓練「指モード」の実装

・さらに軽量化１２０M→６０Mを成功させる。Textureの軽量化。
・しかし、根本の部分で大失敗をする。君の前世の想定ではほぼ無料でできるとの判断だったが、数千円の請求が来た。データのダウンロードにお金がかかっている。このようなものを見落とすという大失態だ。しかも改善方法がない。つまり、無料でFirebase環境に移行できるというから移行したが、継続的に課金が発生している状態だ。
