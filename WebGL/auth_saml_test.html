📋 SAML認証について

  • SAML認証: 学校や企業で使用されるエンタープライズ認証
  • Firebase Custom Auth: SAML認証をFirebaseと連携
  • カスタムトークン: サーバー側でSAML認証を行い、Firebaseトークンを生成
  • 学校環境対応: ポップアップブロックを回避

🎯 実装手順

  1. SAML認証サーバーを構築
  2. Firebase Admin SDKでカスタムトークン生成
  3. クライアント側でカスタムトークンを使用して認証
  4. 学校環境でポップアップなしの認証を実現
